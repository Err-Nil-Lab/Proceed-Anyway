# PROCEED ANYWAY

Boxy 2D survival arcade by ERR NIL. TypeScript, KAPLAY, Vite.

Survive one arena while the system breaks its own rules: hazards telegraph before they hit, and errors change how the game plays for a few seconds. Die instantly, restart instantly.

## Controls

- A / D or Left / Right: move.
- Space / W / Up: jump (tap for a short hop, hold for a higher jump).
- Enter / Space: start and restart.

## Run

```sh
npm install
npm run dev
npm run build   # type-check + production build
```
